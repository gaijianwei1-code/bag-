## 关键验证：初始位姿自动提取（既定决定 2 的核心）
```
自动提取（bag 前 5s，98 条样本中位值）:
  x=0.556011438369751  y=0.025900661945343018  yaw=-0.0005394914218578742
b_line_run.py 硬编码默认值:
  x=0.556011438369751  y=0.025900661945343018  yaw=-0.0005394914218578743
```
**逐位一致**（yaw 差 1 ulp，浮点末位）。这证明"从 bag 自动提取"能完全替代人工填值，且比人工更准。
提取器：`sim-bridge/scripts/extract_init_pose.py`，容器内跑（rosbag 依赖 ROS），取前 5 s 中位值抗抖。
bag 无 `/ndt/current_pose` → `INIT_POSE_MISSING` 明确报错，不静默跑错（实测 T05 bag 触发）。

## 架构要点
- **b_line_run 的输入全靠 scene yaml**：`map_dir` / `trajectory` / `initial_x,y,yaw` / `bag` / `world` 都是 scene 字段 → 场地档案天然映射，无需改 b_line_run
- venue schema 新增 `container:` 段（容器内路径；roslaunch 只认容器路径，host 路径无意义）
- 分支快照：`git worktree --detach` + 只拷 `src`/`sim` 子树（仓库 20 G 含 run 产物，不能整体拷）
- 容器约束遵守：全程只 `docker exec` / `docker cp`，未 rm/stop/restart

## 过程修的问题（真回归）
T2.2 引入异步执行后，run 提交立即进入 failed（测试环境无容器），导致 T2.1 的并发守卫用例失效（r2 拿到 202 而非 409）。修法：单测 fixture 里桩掉 `_execute_run`，让它停在 queued，从而真实测到单并发守卫。**这是异步化带来的真实行为变化，不是堆测试**。
