## 三、过程中修掉的真问题

1. **`QDesktopServices::openUrl` 直接打开 `/report` 必然 401**
   浏览器发的普通 GET 带不了 `X-Bridge-Token`。若按最初写法实现，「查看对比报告」
   按钮永远失败。改为 QNAM 先取回内容 → 写临时文件（或弹保存框）→ 再交系统打开。
2. **`_gates_table` 把"没数据"渲染成 FAIL**
   老版 `compare.json` 无 `not_computable` 字段，`bag_replay_diff.py` 在缺数据时
   仍给 `checks[key] = False`（源码注释明确说"never silently pass"）。直读 `checks`
   会让 `theta_rms`（值 `None`）显示成 FAIL，冤枉仿真。现判据：`checks` 为 `False`
   且实测值为 `None` → 呈现"无数据"，计入 `na` 而不是 `failed`。
3. **报告被当成 JSON 解析**
   `onNetworkFinished` 里先 `QJsonDocument::fromJson` 再按 URL 分支，HTML
   会被解析成空文档后落进笼统的 run 详情分支（表现为"点报告没反应"）。改为
   在读取响应体后**最先**分流 `/report`。
