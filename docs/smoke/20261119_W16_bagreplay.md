## bag_replay.py 关键接口
```
--mode closed --bag <bag> --map-dir <dir>
--baseline-param-set <dir> --candidate-param-set <dir>
--session-id <id> --duration <s>
--scene <scene_yaml>    ← bag 缺 /odom/imu 时必须带（场景提供 world，fake_chassis 发 odom）
```
输出三处：
- `runs/BLINE/{id}_base|_cand/summary.json` → baseline/candidate 各自指标
- `runs/BAG_REPLAY/{id}/compare.json` → F 门对比
- `runs/BAG_REPLAY/{id}/compare.md` → 人类可读对比
