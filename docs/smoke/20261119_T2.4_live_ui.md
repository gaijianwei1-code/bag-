|---|---|
| `LiveOverlayItem` | 单个非交互 `QGraphicsObject`，一次 paint 画完五层：真值轨迹（灰虚线）/ 直播轨迹（橙实线）/ 前视命中点（红点）/ carrot（绿十字）/ 车辆（蓝三角，随 yaw 旋转） |

## 冒烟 10/10 PASS
- overlay 存在 / z 高于地图(0) / z 低于选区(1000)
- **场景 clear 后 overlay 能重建不崩溃**（T1.5 踩过的坑，此处继承防护）

- 连续 attach 5 次无泄漏
- 无 dock 时状态仍可读

## 冒烟抓出的真 bug
`FAIL: run_id 为空应报 error 而非静默`
根因：`m_state` 只在 dock 的 `stateChanged` 回调里赋值 → **没有 dock 时状态读不到**。
修复：所有 `emit stateChanged(...)` 之前先给 `m_state` 赋值（6 处）。
这是"状态机状态依赖 UI 存在"的设计缺陷，不是测试问题。

## 构建改动
CMakeLists 加 `Qt6::Network` + `Qt6::WebSockets`（工具链自带，无需安装）；
`QT_LIBS` 与 `find_package` 同步；`live_layer.{h,cpp}` 加入源文件列表。
Qt6.5+ 用 `errorOccurred`（`error` 已 deprecate），用版本宏兼容旧版。

## 使用方式（待端到端联调确认）
1. `bash docs/smoke/run_smoke.sh` 或手动起 bridge：`uvicorn app:app --port 9100`
2. 提交 run：`POST /runs`（venue_id + 分支 + 轨迹）
3. MapTool 打开同一场地的 pgm + yaml
4. 菜单 →「直播跟车」→ 填 `ws://127.0.0.1:9100` + run_id + token → 连接
5. 车图标应沿轨迹移动，红点显示前视命中，橙线与灰虚线对比偏差
