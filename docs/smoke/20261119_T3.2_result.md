## L0 命中 0 的归因（已核实，非代码 bug）
**容器内 pcd 与本地版本不同**：
```
容器内  1793346971223_frames_no_ground.pcd: 497,134 点  z ∈ [-0.3, 32.98]
本地    ../Downloads/scenario_.../...pcd:  147,448 点  z ∈ [-1.82, 2.70]
```
L0 用 `zmin=0.05, zmax=2.0` 过滤，容器内这份点云 z 起点是 -0.3（含更多地面/远处结构），
过滤后车附近 2 m 内只剩 51 个点且 z≈0（地面点）→ 视锥内确实无"障碍"。

**结论：L0 判"无命中"是正确行为**（车静止在空旷处，周围 2 m 内无高于地面的障碍）。
