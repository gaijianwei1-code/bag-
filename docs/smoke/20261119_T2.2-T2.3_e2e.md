## 关键教训
1. **端到端不可省**：T2.2 起初只验了「位姿提取脚本」（不依赖 adam_msgs），据此判 PASS 是错的。
   真跑一次 b_line_run 才是验收。
2. **日志要逐字读**：端口、路径这类信息就在错误信息里，看趋势不看细节会一直绕。
3. **诊断通道要留够**：非 JSON 行必须进诊断缓冲，否则"没数据"和"没连上"分不清。
4. **不碰别人的 WIP**：主工作区有他人未提交改动（`replay_server.py` 加 scene_yaml 参数）时，
   用 `git stash` 临时隔离建立干净基线验证，验完立即 `git stash pop` 还原。
